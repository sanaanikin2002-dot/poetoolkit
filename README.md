# Exile Toolkit

Набор инструментов для Path of Exile 1 и Path of Exile 2 под Windows.

## Скачать

[Скачать последнюю версию ExileToolkit.exe](https://github.com/sanaanikin2002-dot/poetoolkit/releases/latest/download/ExileToolkit.exe)

Положите EXE в отдельную папку с доступом на запись и запустите. Установка и права администратора не нужны. Нужны Windows 10/11 и .NET Framework 4.8.

## Обновления

Программа проверяет новые версии при запуске. Для установки откройте **«О программе» → «Обновить»** и подтвердите перезапуск.

Настройки, сборки, фильтры и сохранённые крафты остаются на месте. Обновляется только EXE; прежняя версия сохраняется в файле `ExileToolkit.exe.previous`.

Если пользуетесь версией до 1.58.0, один раз скачайте новый EXE по ссылке выше, закройте старую программу и замените её EXE. Остальные файлы рядом оставьте как есть.

## Возможности

- Запуск игры, установка и обновление PoB и торговых помощников.
- Path of Building внутри программы, просмотр сборок и оценка их стоимости.
- Цены poe.ninja, рыночный рейтинг механик фарма, новости и быстрые ссылки.
- NeverSink и собственные фильтры со звуками.
- Для PoE 1: мастерская крафта, моды и шансы, пошаговый советник, сравнение крафта с покупкой.

Цены и шансы приблизительные. Рейтинг фарма не измеряет доход в час. Часть механик крафта пока не поддерживается.

В этом репозитории публикуются только готовая программа, описания и выпуски. Исходники не размещаются.

Exile Toolkit не связан с Grinding Gear Games. Данные предоставляют poe.ninja, RePoE, Path of Building Community и другие независимые проекты; материалы Path of Exile принадлежат их правообладателям.
